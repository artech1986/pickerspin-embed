# Stream overlay (OBS or Streamlabs)

Add a **Browser** source with this URL:

```
https://pickerspin.co/embed/wheel/?obs=1&entries=Alice,Bob,Carla,Dev&title=Giveaway
```

- The background is transparent and the wheel fills the source.
- There is no button. Right click the source, choose **Interact**, then click the
  wheel or press Space.
- `&remove=1` takes each winner off the wheel, `&sound=0` mutes the ticks and
  `&button=1` brings the button back.

pickerspin.co/spin-the-wheel-for-twitch/ builds the URL for you.
